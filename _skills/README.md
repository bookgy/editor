# Skills del Editor

Las Skills se mantienen pequeñas y especializadas. Todas comparten las reglas de `_fuentes/` y `_referencias/`.

Los temas editoriales y todas sus piezas se almacenan en `bookgy/editor/entradas-editor/`.

- `entrada-semilla`: crea la semilla maestra de un tema dentro de `entradas-editor/`.
- `entrada-blog`: crea el blog desarrollado a partir de una semilla.
- `entrada-linkedin`: crea nuevas publicaciones de LinkedIn.
- `entrada-instagram`: crea nuevas publicaciones o conceptos creativos de Instagram.
- `entrada-x`: crea nuevas publicaciones para X.
- `entrada-tiktok`: crea nuevas piezas o guiones para TikTok.
- `newsletter-semilla`: crea la composición editorial de una newsletter utilizando temas de `entradas-editor/`.
- `newsletter`: redacta la newsletter final.

El blog es una pieza derivada opcional. LinkedIn, Instagram, X y TikTok pueden crearse directamente desde la semilla aunque `blog.md` no exista.

Las Skills pueden escribir en `bookgy/editor` cuando la tarea lo requiera. El repositorio `bookgy/oraculo` es siempre de solo lectura.
