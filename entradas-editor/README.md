# Entradas Editor

Cada carpeta representa un tema editorial independiente.

Formato:

`AAAA-MM-NNN-contenido/`

Contenido habitual:

```text
semilla.md
blog.md
linkedin-001.md
linkedin-002.md
instagram-001.md
x-001.md
tiktok-001.md
```

Solo `semilla.md` es obligatoria para iniciar una entrada. El resto de piezas se crea cuando sea necesario.

`blog.md` es una pieza derivada opcional y no es un paso obligatorio previo para crear contenidos de otros canales.

Para añadir un nuevo contenido de un canal, utilizar el siguiente número libre de ese canal dentro de la carpeta.

Todos los temas editoriales y sus piezas se almacenan en `bookgy/editor/entradas-editor/`.
