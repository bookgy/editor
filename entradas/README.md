# Entradas

Cada carpeta representa un tema editorial independiente.

Formato:

`AAAA-MM-NNN-contenido/`

Contenido habitual:

```text
semilla.md
entrada.md
linkedin-001.md
linkedin-002.md
instagram-001.md
x-001.md
tiktok-001.md
```

Solo `semilla.md` es obligatoria para iniciar una entrada. El resto se crea cuando sea necesario.

Para añadir un nuevo contenido de un canal, utilizar el siguiente número libre de ese canal dentro de la carpeta.
